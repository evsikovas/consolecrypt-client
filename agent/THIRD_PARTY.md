# Source and license inventory

ConsoleCrypt-owned source is covered by the repository GNU AGPL version 3 license, copied as `LICENSE`. Preserve existing source copyright notices.

* `identity/vendor/libsqlite3-sys` is the reviewed 0.38.2 SQLite component. Its upstream crate license, SQLCipher license and exact source file inventory are retained. `third_party/sqlite/SOURCE.json` records the two-reader WAL backport and source digest. A copied vendor directory alone does not prove that a binary selected it.
* `third_party/websockets` contains the exact websockets 17.4 pure-Python wheel (BSD-3-Clause) and its full LICENSE. No dependency is downloaded or installed at runtime.
* `third_party/prometheus-agent` contains the exact upstream Apache-2.0 LICENSE/NOTICE, pinned Go module inputs, reviewed native-WAL patches and additive source. It does not contain an upstream repository clone. Any distributed collector binary must be accompanied by its complete verified corresponding source and dependency notices; the overlay manifest alone is not that source bundle.
* Other Rust and Go dependencies remain pinned in their lock/module inputs. A final device artifact must generate notices from the dependencies actually selected by that build. A historical prototype binary notice inventory is not reused as a current SBOM.

The client source exporter includes this public feature folder while excluding caches, target outputs, evidence, private state and unknown binary files. No release archive or binary/source compliance claim is generated by this source copy.
