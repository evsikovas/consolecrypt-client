# Finite collector prerequisite

`status` reads the installed fixed unit. `prepare` explicitly enables the
verified installed disk collector daemon after the original signed installation
and disk prerequisites. It does not enroll a Node, sign a grant, or begin
collection. Native confirmation separately binds the actual registered Metrics
Node and exact administrator-selected full manifest for at most 24 hours and
32 starts. There is no automatic renewal.

`disable` stops the daemon and asks its original worker to join the owned unit.
It preserves signed history, quota/replay state and WAL. Disabling infrastructure
does not issue targeted signed revocation or erase retained data.

Same-OS-boot daemon restart retains the original signed BOOTTIME deadline and
start quota. A changed OS boot or unresolved previous unit is refused and needs
explicit reconciliation/approval; it is not silently resumed or adopted.
