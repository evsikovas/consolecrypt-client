# Nerd Fonts symbols used by ConsoleCrypt

ConsoleCryptSymbols.ttf contains the Material Design Icons subset of the Nerd Fonts
v3.5.1 Symbols Nerd Font Mono. ConsoleCrypt reduced the font to the Material Design
code points and derived symbols.json from that release's glyphnames.json.

- https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1
- https://github.com/Templarian/MaterialDesign-Font
- https://pictogrammers.com/

Material Design desktop fonts are distributed under Apache License 2.0.
The text of that license is included as assets/fonts/Roboto-LICENSE.txt.
