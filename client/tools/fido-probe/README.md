# fido-probe (FEAT-16, прототип)

Отвечает на один вопрос до разработки функции: даёт ли Windows (`webauthn.dll`)
обычной программе стабильный секрет hmac-secret / PRF от USB-ключа (YubiKey).

1. Вставьте ключ и запустите `fido-probe.exe` (права администратора не нужны).
2. Регистрация: Windows спросит PIN ключа и попросит коснуться его.
3. Четыре проверки: PRF дважды и «сырой» hmac-secret дважды — каждый раз PIN и касание.
4. Пришлите `fido-probe-report.txt` из папки программы.

В отчёте только SHA-256 отпечатки ответов ключа, сами секреты не сохраняются.
`fido-probe-credential.bin` — идентификатор зарегистрированного ключа: повторный
запуск пропускает регистрацию. Удалите файл, чтобы зарегистрировать заново.
Запись «ConsoleCrypt fido-probe» на ключе можно удалить в
«Параметры → Учётные записи → Варианты входа → Ключ безопасности → Управление».
