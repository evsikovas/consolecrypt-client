# ConsoleCrypt 0.5.7

## Русский

Исправлена панель уведомления об обновлении. Наведение на кнопку загрузки
больше не вызывает белый экран; нажатие открывает подтверждение установки.
После подтверждения панель показывает ход загрузки. Отмена и закрытие
уведомления работают независимо от загрузки.

Если во время подтверждения появился другой выпуск, приложение не начинает
его установку без нового подтверждения.

Возможности 0.5.6, включая мобильный RDP-тачпад и адаптивный Recovery Kit,
сохранены. Обновление использует существующие хранилища, ключи и локальные
модели ИИ.

## English

Fixed the update notification banner. Hovering over the download button no
longer opens a blank screen, and clicking it opens the installation
confirmation. The banner shows download progress after confirmation.
Cancelling the confirmation and dismissing the notification work independently.

If a different release becomes available while confirmation is open, it is
not installed without a new confirmation.

This release retains the 0.5.6 features, including the mobile RDP touchpad and
responsive Recovery Kit, and reuses existing vaults, keys and local AI models.
