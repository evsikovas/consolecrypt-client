# ConsoleCrypt 0.1.13 · проверка выпуска

Дата: 30 сентября 2026 года. Исходники — тег `v0.1.13`, commit `4dd26f2`.
Используется настоящий Rust bridge; `CC_MOCK=false`.

| Платформа | Пакеты | Нативная версия |
|---|---|---|
| Windows 10/11 x64 | EXE и переносимый ZIP | 0.1.13+1221 |
| macOS Apple Silicon и Intel | Универсальный DMG | 0.1.13+1222 |
| Android 11+ ARM64 | APK | 0.1.13+27 |

Исправлена регрессия, когда Windows обрабатывал Enter, но не обычные символы.
Теперь событие hardware keyboard передаёт Unicode текущей раскладки; Flutter
помечает событие обработанным, чтобы OS text input не дублировал символ.
IME-композиция продолжает использовать native TextInput. Регрессионный тест
воспроизводил отказ до исправления и проходит после него: `ф`, `Я`, `ё`, пробел,
обычная латиница, удержание клавиши и Enter. Прежние проверки фокуса, скрытой
вкладки, IME и Ctrl+C сохранены. Это тест событий Flutter, а не доказательство
работы физической клавиатуры на всех Windows-компьютерах.

Добавлен раздел «Обновления»: автопроверка при запуске, её отключение, ручная
проверка и скачивание/запуск установщика. Метаданные подписаны Ed25519, HTTPS
загрузки ограничены доверенными адресами, SHA-256 проверяется до установки.
Проверены неверные подписи, подмена ключа, срок действия, запрет отката,
обрезанные/слишком большие файлы, неверный digest, перенаправление на чужой
домен, сохранение переключателя, повтор после ошибки, Android permissions
round trip и отмена установки пользователем.

GitLab pipeline155 / jobs1221,1222 успешно собрали Windows и macOS.
Статический анализ и все 406 Flutter-тестов прошли на обоих раннерах.
ZIP прошёл CRC; Windows version resource содержит 0.1.13+1221.
DMG прошёл проверку целостности, `codesign --verify --deep --strict`, проверку
bundle version1222 и архитектур x86_64/arm64; внутри есть Applications link.
APK содержит versionName0.1.13/versionCode27, прошёл проверку подписи,
`zipalign -P 16` и проверку ELF alignment всех трёх native библиотек.
Сертификат APK совпадает с прошлой версией, поэтому установка поверх совместима.

Закрытый издатель обновлений развёрнут независимо от API и сайта, вне
публичного Git. Он читает релизы каждые пять минут, проверяет пакеты всех
платформ и подписывает feed. Клиент Dart проверил реальную подпись Node.
Ключ подписи доступен только издателю; web Pod его не получает. Данные
хранилищ и учётных записей не участвуют в проверке обновлений.

Ограничения: установка ещё требует приёмочной проверки на проблемных Windows10
компьютерах и физическом Android. Windows запускает Inno installer и закрывает
клиент; Android требует системного подтверждения; macOS открывает DMG для
замены приложения пользователем. Установщики в этом прогоне не запускались
для замены существующих приложений. Пакеты остаются предварительными:
Windows без Authenticode, macOS без Apple notarization, APK с прежним
development-сертификатом.
