# Локальный ИИ / Local AI

В Windows и macOS откройте «Настройки» → «Встроенный локальный ИИ» →
«Установить локальный ИИ».
Клиент скачает Qwen2.5-Coder 1.5B Instruct Q4_K_M (1 117 320 768 байт).
В macOS небольшой движок llama.cpp включён в подписываемый пакет приложения,
чтобы работать внутри App Sandbox; в Windows движок скачивается отдельно. Видны прогресс и отмена; прерванная загрузка продолжается
при следующей установке. Файлы проверяются по закреплённым SHA-256 до запуска.
Большой файл модели не включается в установщик ConsoleCrypt.

[Руководство со скриншотами установки, загрузки и готовой модели](https://consolecrypt.dev/guide?lang=ru#local-ai)
также доступно [на английском](https://consolecrypt.dev/guide?lang=en#local-ai).
На снимках показаны настоящие виджеты 0.4.1 с демонстрационными состояниями;
это не запись загрузки или ответа реальной модели.

Флажок «Использовать по умолчанию после установки» изначально включён. Он начинает
действовать после установки и хранится только на этом компьютере. Облачные
провайдеры и их синхронизируемый выбор сохраняются; снятие флажка возвращает их
обычный выбор. Ни путь к модели, ни случайный токен процесса не попадают в vault.

Модель запускается при первом запросе, а также кнопкой «Запустить». Через 15 минут
без запросов она выгружается; активная генерация удерживает процесс. Блокировка
vault, смена профиля и выход останавливают процесс. «Удалить» удаляет локальную
установку. На Apple Silicon используется Metal; на Intel Mac и Windows x64 — CPU-движок.
Android и Linux не показывают этот раздел; мобильный клиент не скачивает модель.

Запросы идут только на `127.0.0.1` со случайным токеном текущего запуска. Системный
HTTP-прокси для локальных запросов отключён. Контекст, фильтрация секретов и
подтверждение команд работают через существующее ядро ConsoleCrypt. Интернет
нужен при установке модели и Windows-движка; inference выполняется на компьютере.

## Компоненты

- [llama.cpp b11739](https://github.com/ggml-org/llama.cpp/releases/tag/b11739), MIT,
  закреплённые архивы для macOS ARM64/x64 и Windows x64 CPU.
- [Qwen2.5-Coder-1.5B-Instruct-GGUF](https://huggingface.co/Qwen/Qwen2.5-Coder-1.5B-Instruct-GGUF),
  Apache-2.0; ревизия `f86cb2c1fa58255f8052cc32aeede1b7482d4361`, Q4_K_M.
- Dart `archive` 4.5.2, MIT, используется для контролируемой распаковки.

Каталог URL, размеров и SHA-256: `client/flutter/lib/ai/local/local_ai_catalog.dart`.
Сторонние компоненты сохраняют свои лицензии. Автоматической установки при
открытии приложения нет. Выбор произвольного GGUF и CUDA-пакета пока не реализован.

## Проверка разработчиком

Unit/widget тесты не скачивают модель. Для отдельной проверки настоящего движка:

```sh
cd client/flutter
dart run test/ai/local/local_ai_smoke.dart --run --directory=/absolute/test/cache
```

Команда проверяет установку, авторизацию, ответ модели и idle lifecycle. Для
быстрой проверки только скачанного движка добавьте `--runtime-only`. Не используйте
папку с пользовательской моделью как тестовый каталог.
