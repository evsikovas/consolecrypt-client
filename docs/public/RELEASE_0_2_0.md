# ConsoleCrypt 0.2.0 · Терминал, поиск и совместная работа

Дата: 1 октября 2026 года. Исходный код: тег `v0.2.0`,
commit `dff126c8298b6b9e51f6169df8d407de07c39738`.

## Что изменилось

- **Терминал:** колесо мыши и трекпад работают при выделенном тексте.
  Если при выделении перетащить указатель выше или ниже терминала,
  буфер прокручивается, а выделение продолжается.
- **Ввод:** после работы со сниппетами, ИИ и правой панелью достаточно
  одного клика по терминалу. Исправлены гонки фокуса при закрытии
  всплывающей панели и уходе из поля ввода закреплённой панели.
- **Быстрое подключение:** `Ctrl+K` / `Cmd+K` ищет сохранённые хосты
  по имени, IP-адресу и имени пользователя. В результатах видны адрес,
  пользователь и порт, включая настройки группы. `Enter` подключает
  выбранный хост через обычную проверку ключа и учётных данных.
  Поиск хостов и сниппетов выполняется локально; запрос к ИИ требует
  явного выбора действия ИИ.
- **Рабочее пространство:** начальное окно Windows/macOS увеличено
  до 1440 × 900 с ограничением по доступной области экрана.
  При переполнении полосы вкладок виден общий счётчик `(N)`.
  На узком окне инструменты переходят на следующую строку.
- **Совместная работа:** публичный сервер поддерживает общий доступ,
  группы, секреты и подтверждённое добавление собственных устройств.
  В клиенте кнопка обновления повторно проверяет доступность функций,
  даже если предыдущая проверка вернула «недоступно».
  Ошибки подключения и авторизации отображаются отдельно.
  Публикация выбранных данных требует действия владельца.
- **Лицензия:** в окне «О программе» отображается краткое название
  `AGPL-3.0`. Формальный идентификатор `AGPL-3.0-only` и полный текст
  лицензии сохранены. Сторонние компоненты сохраняют свои лицензии.

## Проверки

- Flutter: **499 тестов PASS**, анализ без замечаний. Регрессионные
  тесты проверяют выделение и прокрутку, возврат фокуса, кириллицу и IME,
  оба режима правой панели, поиск хостов и повторную проверку sharing.
- [Pipeline 190](https://git.evsikov.net/publics/consolecrypt/-/pipelines/190):
  Windows job 1257 и macOS job 1258 успешно выполнили анализ,
  полный набор Flutter-тестов и сборку до упаковки.
- Локальные сценарии версии, экспорта и упаковки: **20 PASS, 1 SKIP**;
  пропущенная на macOS проверка требует PowerShell.
- Проверены версии EXE и установщика Windows, комплект runtime DLL,
  целостность ZIP; DMG, universal architectures и deep/strict codesign;
  прежний сертификат APK и выравнивание ELF/ZIP для 16 KiB;
  ARM64/Intel slices и точная сборка ZIP из двух частей iOS Simulator.
- Полный текст AGPL включён и проверен во всех четырёх пакетах.
- Все семь публичных файлов анонимно скачаны; размеры и SHA-256
  совпадают с локальными проверенными пакетами.
- Сервер обновлений публикует 0.2.0 для Windows 1257, macOS 1258
  и Android 58. Подпись Ed25519 проверена прежним публичным ключом
  клиента; ссылки, размеры и SHA-256 совпадают с проверенными пакетами.
- Руководство обновлено на русском и английском: **29 разделов,
  72 изображения**, включая поиск хостов, прокрутку выделения,
  счётчик вкладок и оба режима панели. Снимки сделаны из реальных
  виджетов клиента 0.2.0 с демонстрационными данными.

Интерактивная приёмка на физических Windows/Android/iPhone устройствах
в этом прогоне не выполнялась. Чтобы повторить проверку функций
публичного сервера, установите 0.2.0 и нажмите обновление в разделе
«Совместный доступ».

## English

ConsoleCrypt 0.2.0 restores one-click terminal focus after workspace tools,
keeps text selection scrollable, and adds local host search by name or IP
with `Ctrl+K` / `Cmd+K`. Desktop windows start larger, overflowing terminal
tabs show their total count, and narrow layouts keep the session tools
accessible. Sharing support can be checked again after an unavailable
result; connection and authentication errors are shown separately.

The public server now enables sharing, shared groups, shared secrets and
confirmed enrollment of your own devices. Data is shared only through an
explicit owner action. The bilingual guide includes 29 chapters and 72
illustrations. All 499 Flutter tests passed, both desktop CI builds
succeeded, and every published package was downloaded and checked against
SHA-256. Physical-device interactive acceptance was not performed.
