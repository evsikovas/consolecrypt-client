# ConsoleCrypt 1.2.0

## Русский

- **Автоматизация.** Библиотека проектов Ansible с плейбуками, ролями, версиями, импортом из Git и зашифрованными архивами. ИИ готовит черновик, а вы проверяете изменения перед запуском. Выбирайте цели из хостов ConsoleCrypt, файлов inventory INI/YAML или обоих источников.
- **Runner и расписания.** Ansible на поддерживаемых Mac запускается нативно через локальный Python. Windows поддерживает локальный запуск через WSL2. Для запуска по расписанию при закрытом клиенте нужен настроенный серверный Runner. На телефоне для автоматизации используйте удалённый Runner.
- **Терминал.** Отдельный режим «Только терминал» для быстрых локальных сессий. В нём есть палитра команд, выбор оболочки и вкладки слева или сверху. В активной SSH-сессии значок графика справа открывает сведения о сервере и доступные метрики.
- **Пароли.** Быстрый доступ к пяти недавним базам KDBX, значки записей и групп, синхронизация настроек подключений WebDAV. Файл KDBX хранится на WebDAV. На Android исправлено открытие локальных и WebDAV-баз с помощью отпечатка или системного PIN.
- **Интерфейс.** Испанский и упрощённый китайский добавлены к русскому и английскому. Язык можно сменить в настройках или на экране приветствия. Порядок разделов боковой панели можно менять.

Пакеты выпускаются для Windows, macOS, Linux DEB/RPM и Android ARM64. Отдельно доступны APK и AAB для RuStore. Сборка iOS предназначена для Simulator на Mac.

## English

- **Automation.** Manage Ansible projects with playbooks, roles, versions, Git imports, and encrypted archives. AI drafts changes for you to review before a run. Choose targets from ConsoleCrypt hosts, INI/YAML inventory files, or both.
- **Runners and schedules.** Ansible runs natively with local Python on supported Macs. Windows supports local execution through WSL2. To run on a schedule when the app is closed, configure a server Runner. Use a remote Runner for automation on mobile.
- **Terminal.** Terminal Only opens a lightweight workspace for local sessions. It includes the command palette, shell selection, and tabs on the left or top. In an active SSH session, the chart icon on the right opens server details and available metrics.
- **Passwords.** Quickly reopen five recent KDBX databases, assign icons to entries and groups, and sync WebDAV connection settings. The KDBX file stays on WebDAV. On Android, fingerprint and system PIN unlock work for local and WebDAV databases.
- **Interface.** Spanish and Simplified Chinese join Russian and English. Switch languages in Settings or on the Welcome screen. Sidebar sections can be reordered.

Packages cover Windows, macOS, Linux DEB/RPM, and Android ARM64. Separate RuStore APK and AAB packages are available. The iOS build runs in Simulator on Mac.

## Español

- **Automatización.** Gestiona proyectos de Ansible con playbooks, roles, versiones, importación desde Git y archivos cifrados. La IA prepara borradores para revisar antes de ejecutar. Puedes seleccionar los destinos desde los hosts de ConsoleCrypt, desde archivos de inventario INI/YAML o desde ambos.
- **Runner y tareas programadas.** Ansible funciona de forma nativa con Python local en los Mac compatibles. En Windows, la ejecución local se realiza mediante WSL2. Para programar tareas con la aplicación cerrada, configura un Runner de servidor. En el móvil, usa un Runner remoto.
- **Terminal.** El modo «Solo terminal» ofrece un espacio para sesiones locales con paleta de comandos, selección de intérprete y pestañas a la izquierda o arriba. Durante una sesión SSH, el icono del gráfico a la derecha muestra la información del servidor y las métricas disponibles.
- **Contraseñas.** Vuelve a abrir las cinco bases KDBX recientes, asigna iconos a entradas y grupos y sincroniza los ajustes de WebDAV. El archivo KDBX permanece en WebDAV. En Android se ha corregido el desbloqueo con huella o PIN del sistema para las bases locales y las de WebDAV.
- **Interfaz.** El español y el chino simplificado se suman al ruso y al inglés. El idioma se elige en Ajustes o en la pantalla de bienvenida. Se puede cambiar el orden de las secciones de la barra lateral.

Hay paquetes para Windows, macOS, Linux DEB/RPM y Android ARM64. RuStore dispone de APK y AAB separados. La compilación de iOS se ejecuta en Simulator en Mac.

## 简体中文

- **自动化。** 管理 Ansible 项目的 Playbook、角色和版本，支持从 Git 导入以及使用加密归档。AI 生成的修改会先交给你检查。目标可以来自 ConsoleCrypt 主机、INI/YAML 清单文件，或同时来自两者。
- **Runner 和计划任务。** 在受支持的 Mac 上，可使用本地 Python 原生运行 Ansible。Windows 支持通过 WSL2 在本地运行。关闭应用后仍需按计划运行时，请配置服务器 Runner。移动端的自动化任务使用远程 Runner。
- **终端。**「仅终端」模式适合快速开启本地会话，支持命令面板、Shell 选择以及在左侧或顶部显示标签页。在 SSH 会话中，点击右侧图表图标可查看服务器信息和可用指标。
- **密码。** 快速打开最近使用的五个 KDBX 数据库，为条目和分组设置图标，并同步 WebDAV 连接设置。KDBX 文件仍保存在 WebDAV 上。Android 已修复本地和 WebDAV 数据库的指纹或系统 PIN 解锁。
- **界面。** 在俄语和英语之外新增西班牙语和简体中文。可以在设置或欢迎界面切换语言，也可以调整侧边栏中各功能的顺序。

提供 Windows、macOS、Linux DEB/RPM 和 Android ARM64 安装包。RuStore 另有专用 APK 和 AAB。iOS 版本在 Mac 上的 Simulator 中运行。
