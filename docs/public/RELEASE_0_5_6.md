# ConsoleCrypt 0.5.6

## Русский

Исправлено отображение Recovery Kit на телефоне. Количество колонок со словами
теперь зависит от ширины экрана и размера текста. На узком экране QR-код
располагается ниже слов; номера и слова не перекрываются. Поддерживается
увеличенный системный шрифт.

В выпуск входят полноэкранный мобильный RDP с относительным тачпадом,
экранной клавиатурой и настройками жестов, импорт SSH-хостов из `known_hosts`,
локальный терминал в палитре команд и исправление отступа от системных кнопок
macOS. Подробнее: [изменения 0.5.5](RELEASE_0_5_5.md).

Существующие хранилища, ключи и скачанные локальные модели ИИ сохраняются.

## English

Recovery Kit words now use a responsive column count based on screen width
and text scaling. The QR code moves below the words on narrow screens, keeping
the numbered words readable without overlap, including larger system fonts.

This release includes fullscreen mobile RDP with a relative touchpad, keyboard
and gesture settings, SSH host import from `known_hosts`, the local terminal
command-palette action and the macOS window-control spacing fix.
See [the 0.5.5 changes](RELEASE_0_5_5.md) for details.

Existing vaults, keys and downloaded local AI models are preserved.
