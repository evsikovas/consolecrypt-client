# ConsoleCrypt 0.1.10 · проверка выпуска

Дата: 30 сентября 2026 года. Исходники — неизменяемый тег `v0.1.10`.
Клиент использует настоящий Rust bridge; `CC_MOCK` не включён.

| Платформа | Пакет | Номер сборки |
|---|---|---|
| Windows 10/11 x64 | EXE и переносимый ZIP | 1208 |
| macOS Intel / Apple Silicon | Универсальный DMG | 1209 |
| Android 11+ ARM64 | APK | 22 |

Исправлены повторное подключение native TextInput при активации терминала,
фокус только видимой вкладки и передача фокуса дочернему окну Flutter на Windows.
Ввод текста остаётся через IME; UTF-8 кириллица передаётся без преобразования
в раскладку клавиш. Скрытая вкладка и окно подтверждения не перехватывают ввод.

Windows и macOS построены проектными GitLab runners (pipeline150, jobs1208/1209).
`flutter analyze`, все 393 Flutter-теста и 6 тестов версионирования прошли
на обоих хостах. Регрессии проверяют один клик после потери фокуса,
`Привет, ёж!`, IME-композицию, переключение вкладок, Enter и Ctrl+C.
Windows служба находит установленные инструменты; недостающие Flutter, Perl
и Inno Setup берутся из официальных релизов с проверкой commit/SHA-256.

Контрольные суммы скачанных DMG/EXE/ZIP совпали с CI-артефактами. ZIP прошёл
проверку CRC и содержит EXE, Rust bridge, Flutter, ICU и DLL Visual C++.
DMG прошёл `hdiutil verify`; внутри версия0.1.10, build1209, архитектуры
x86_64 и arm64, ссылка Applications и корректная проверка `codesign --verify`.
Приложение на этом Mac в ходе проверки не запускалось.

APK собран из того же публичного дерева с новым build22. Проверены package
`io.consolecrypt.consolecrypt`, versionName0.1.10, versionCode22, подпись,
`zipalign -P 16` и 16KiB ELF layout всех трёх native библиотек.
Сертификат подписи совпадает с предыдущим APK, поэтому обновление совместимо.

Нативная проверка клавиатуры на двух конкретных проблемных компьютерах Windows10
остаётся пользовательским приёмочным тестом: эта машина не имеет их рабочего
стола. После обновления проверьте переключение из другого приложения в терминал,
ввод русской и английской раскладки, выделение текста, переключение SSH-вкладок
и возвращение фокуса после закрытия диалога. Нельзя считать имитацию IME в
автотесте полной проверкой физической клавиатуры каждого компьютера.

Пакеты предназначены для предварительного тестирования. Windows без подписи
издателя, macOS без нотариализации Apple, APK использует development-сертификат.
Текущий APK не запускался на физическом телефоне в этом прогоне.

Сервер0.1.9 / протокол1.5 и сайт имеют отдельные версии. Изменение клиента
не требует пересборки сервера. Сайт вынесен в отдельный `consolecrypt-site`.
