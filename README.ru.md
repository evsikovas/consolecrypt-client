# ConsoleCrypt

[English](README.md) · **Русский** · [Español](README.es.md) · [简体中文](README.zh.md)

ConsoleCrypt — клиент с открытым исходным кодом для администрирования серверов. В одном приложении можно открыть терминал SSH, передать файл по SFTP, подключиться к рабочему столу Windows, проверить контейнер или выполнить запрос к базе данных. Подключения хранятся в локальном зашифрованном хранилище. При желании их можно синхронизировать между доверенными устройствами.

[Скачать](https://consolecrypt.dev/download?lang=ru) · [Руководство](https://consolecrypt.dev/guide?lang=ru) · [Последний выпуск на GitHub](https://github.com/evsikovas/consolecrypt-client/releases/latest)

## Что изменилось в 1.2.3

Сведения о хосте открываются под списком. В KeePass группы, записи и поля разнесены по панелям. В Docker можно перетащить разделитель, чтобы расширить сведения о контейнере, или удалить весь Compose-проект и выбрать ресурсы для очистки. SSH-туннели и пробросы портов Docker и Kubernetes показаны в отдельных списках. На экране синхронизации видны изменения, ожидающие отправки.

## Установка

| Платформа | Пакет и требования |
| --- | --- |
| Windows x64 | Запустите EXE-установщик или распакуйте переносную версию из ZIP. |
| macOS · Intel и Apple Silicon | Откройте универсальный DMG. Перетащите ConsoleCrypt, ConsoleCrypt Terminal или оба приложения в папку «Программы». |
| Linux x64 | Для Debian/Ubuntu используйте DEB, для Fedora — RPM. В графическом сеансе нужна разблокированная служба Secret Service с постоянным хранилищем ключей. |
| Android 11+ · ARM64 | Установите APK напрямую или скачайте приложение из [RuStore](https://www.rustore.ru/catalog/app/io.consolecrypt.consolecrypt). В выпуске также есть отдельные APK и AAB для магазина. |
| iOS Simulator | Распакуйте универсальный ZIP для Simulator на Mac с Xcode. Пакет предназначен только для симулятора. |

Для проверки загрузки сравните SHA-256 файла со значением напротив его имени. [Контрольные суммы для 1.2.3](https://github.com/evsikovas/consolecrypt-client/releases/download/v1.2.3/SHA256SUMS-1.2.3.txt).

## Первое подключение

1. Выберите локальный профиль или подключитесь к серверу синхронизации. Создайте хранилище и сохраните комплект восстановления в надёжном месте.
2. Откройте **Хосты**, добавьте SSH- или RDP-хост, укажите адрес и способ входа.
3. При подключении сверьте отпечаток ключа хоста или сертификата с данными из доверенного источника. В SSH-сеансе с Linux откройте **Мониторинг**, чтобы посмотреть нагрузку.

SSH, RDP и SFTP соединяют ваше устройство с целевым хостом напрямую или через настроенный промежуточный узел. Сервер синхронизации обслуживает учётные записи и хранит зашифрованные записи. Ему доступны служебные данные аккаунта, в том числе адрес электронной почты.

## Возможности

- **Терминал и файлы.** Разделяйте терминал на панели, открывайте локальные оболочки и вкладки SSH. Режим «Только терминал» запоминает оформление на устройстве. Пока открыт встроенный SSH-сеанс с Linux, показания снимаются и при закрытой панели мониторинга. Рядом с графиком CPU за последние пять минут видны память, диск и скорость сети. Из этой же вкладки можно открыть SFTP.
- **Пароли.** Открывайте локальные и WebDAV-базы KeePass (KDBX 3/4) и секреты KV v1/v2 в HashiCorp Vault и OpenBao. В палитре команд (Ctrl+K или ⌘K) выберите поле стрелками и нажмите Enter, чтобы скопировать скрытое значение. Сохранённые подключения Vault/OpenBao синхронизируются через личное хранилище. Для каждого подключения можно отдельно включить передачу пароля или токена. Вход по биометрии настраивается на каждом устройстве.
- **Docker и Kubernetes.** Работайте с локальным или удалённым Docker, смотрите логи, управляйте контейнерами, томами и Compose-проектами. В Kubernetes доступны ресурсы, YAML, логи и терминал Pod, а также проброс портов. Экспериментальный мастер переносит в кластер контейнер без постоянных данных, если образ доступен узлам кластера.
- **Базы данных.** Просматривайте структуру и выполняйте запросы в PostgreSQL, MySQL/MariaDB, SQLite, ClickHouse, Redis, MongoDB и Cassandra/ScyllaDB. Подключайтесь напрямую, через SSH-туннель или проброс порта контейнера.
- **Ansible.** Импортируйте проекты из Git, редактируйте плейбуки и файлы inventory, проверяйте изменения и запускайте их на выбранных хостах. Настроенный серверный Runner выполняет задания по расписанию и при закрытом клиенте. На телефоне используется удалённый Runner.
- **Доступ и совместная работа.** Подключайтесь к рабочему столу Windows по RDP. Синхронизируйте подключения, учётные данные и сниппеты между доверенными устройствами. В команде можно поделиться выбранными записями с проверенным получателем. Отзыв доступа не удаляет уже сохранённые им копии.
- **Хранилище и командная строка.** Создавайте зашифрованные резервные копии и настраивайте разблокировку на устройстве. В Windows и macOS можно использовать аппаратный ключ FIDO2 и PIN (предварительная поддержка). В настольные пакеты входит `consolecrypt-cli`.
- **ИИ по выбору.** Попросите подключённого провайдера объяснить выделенный вывод или подготовить команду. На поддерживаемых настольных системах можно запустить локальную модель. Перед отправкой проверьте, какие данные передаются, а перед выполнением — саму команду.

## Сборка из исходников

Общий интерфейс Flutter находится в `client/flutter/`, нативный клиент Rust — в `client/rust/`, модели данных хранилища — в `crates/models/`. Скрипты упаковки для всех платформ находятся в `client/scripts/`.

Установите версию Rust из `rust-toolchain.toml`, Flutter SDK и инструменты для целевой платформы. Для сборки macOS и iOS Simulator нужен Mac с Xcode. Для Windows нужны MSVC и Windows SDK. [Требования к сборке](https://github.com/evsikovas/consolecrypt-docs/blob/main/docs/public/BUILDING.md).

```sh
git clone https://github.com/evsikovas/consolecrypt-client.git
cd consolecrypt-client/client/flutter
flutter pub get
cd ../..
```

| Платформа | Команда из корня репозитория |
| --- | --- |
| macOS | `bash client/scripts/build-macos.sh` |
| Windows | `powershell -File client/scripts/build-windows.ps1 -Installer` |
| Linux | `bash client/scripts/build-linux.sh` |
| Android | `bash client/scripts/build-android.sh` |
| iOS Simulator | `bash client/scripts/build-ios.sh` |

Готовые пакеты появятся в `dist/`. Чтобы обновить установленный Android APK с сохранением данных, нужна та же подпись.

## Запуск тестов

```sh
cargo test --locked --manifest-path crates/Cargo.toml
cargo test --locked --manifest-path client/rust/Cargo.toml
cd client/flutter
flutter pub get
flutter analyze
flutter test
```

Для интеграционных тестов могут понадобиться нативная библиотека, разблокированное системное хранилище ключей или тестовый сервер. В одной рабочей копии запускайте тесты Flutter и нативную сборку по очереди.
